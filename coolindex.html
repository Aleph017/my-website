How this website works

It's hosted on my old Asus K52F laptop. It runs Arch Linux, nginx to serve HTML, CSS and JS. I used myaddr.io and duckdns.org for dynamic DNS, but now the preferred way to connect is my very own domain. The traffic passes through whole 2 routers at my home; I have to keep this unholy setup because of the legacy TV hardware my family uses.

Earlier the lapserver's uptime was scheduled, but recently I bought a real domain and started using local alternative to Cloudflare Tunnel, so I decided to make the server work 24/7 with daily reboot at 3AM UTC.
